[MOCK] ## How to install
[MOCK] 
[MOCK] To install JHipster v8.9.0:
[MOCK] 
[MOCK] ```
[MOCK] npm install -g generator-jhipster@8.9.0
[MOCK] ```
[MOCK] 
[MOCK] It is also available using the JHipster Docker image, as it is automatically built from our source code.
[MOCK] 
[MOCK] - [JHipster Online](https://start.jhipster.tech)
[MOCK] - [JHipster Devbox](https://github.com/jhipster/jhipster-devbox)

[MOCK] ## How to upgrade
[MOCK] 
[MOCK] **Automatic upgrade**
[MOCK] 
[MOCK] For an automatic upgrade, use the [JHipster upgrade sub-generator](/upgrading-an-application/) on an existing application:
[MOCK] 
[MOCK] Upgrade your version of JHipster:
[MOCK] 
[MOCK] ```
[MOCK] npm update -g generator-jhipster
[MOCK] ```
[MOCK] 
[MOCK] And then run the upgrade sub-generator:
[MOCK] 
[MOCK] ```
[MOCK] jhipster upgrade
[MOCK] ```
[MOCK] 
[MOCK] You can also use the [migrate blueprint](https://github.com/jhipster/generator-jhipster-migrate) for more advanced upgrade features.
[MOCK] 
[MOCK] ```
[MOCK] npm i -g generator-jhipster-migrate
[MOCK] jhipster-migrate
[MOCK] ```
[MOCK] 
[MOCK] **Manual upgrades**
[MOCK] 
[MOCK] For a manual upgrade, first upgrade your version of JHipster with:
[MOCK] 
[MOCK] ```
[MOCK] npm update -g generator-jhipster
[MOCK] ```
[MOCK] 
[MOCK] If you have an existing project, it will still use the JHipster version with which it was generated.
[MOCK] To upgrade your project, you must first delete its `node_modules` folder and then run:
[MOCK] 
[MOCK] ```
[MOCK] jhipster
[MOCK] ```
[MOCK] 
[MOCK] Since JHipster 8.0, this command will update your project and all its entities.
[MOCK] 
[MOCK] You can also update your entities one-by-one by running again the entity sub-generator, for example if your entity is named _Foo_, use:
[MOCK] 
[MOCK] ```
[MOCK] jhipster entity Foo --single-entity
[MOCK] ```
