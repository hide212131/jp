[MOCK] # JHipster release v8.10.0
[MOCK] 
[MOCK] This is a minor release for JHipster v8.
[MOCK] 
[MOCK] It includes [455 closed issues and pull requests on the main branch](https://github.com/jhipster/generator-jhipster/issues?q=is:closed+milestone:8.10.0) after the [8.9.0 release](/2025/02/08/jhipster-release-8.9.0.html).
[MOCK] 
[MOCK] ## What's new?
[MOCK] 
[MOCK] * Upgrade to Spring Boot 3.4.4 ([#29096](https://github.com/jhipster/generator-jhipster/pull/29096))
[MOCK] * Implemented workaround for Hazelcast issue with Spring Boot DevTools ([#28750](https://github.com/jhipster/generator-jhipster/pull/28750))
[MOCK] * Fix the handling of falsy values in field annotations ([#28753](https://github.com/jhipster/generator-jhipster/pull/28753))
[MOCK] * Upgrade to Gradle 8.13 ([#28803](https://github.com/jhipster/generator-jhipster/pull/28803))
[MOCK] * Upgrade to Node 22.14.0 ([#28670](https://github.com/jhipster/generator-jhipster/pull/28670))
[MOCK] * Upgrade to TypeScript 5.8.2 ([Angular](https://github.com/jhipster/generator-jhipster/pull/28858), [React](https://github.com/jhipster/generator-jhipster/pull/28856), [Vue](https://github.com/jhipster/generator-jhipster/pull/28857))
[MOCK] * [Angular] Observable to Signal ([password](https://github.com/jhipster/generator-jhipster/pull/29107) and [ribbon](https://github.com/jhipster/generator-jhipster/pull/29095) components)
[MOCK] * [Angular] Use self-closing tags ([#28909](https://github.com/jhipster/generator-jhipster/pull/28909) and [#29090](https://github.com/jhipster/generator-jhipster/pull/29090))
[MOCK] * [Angular] Replace noop with error factory ([#29092](https://github.com/jhipster/generator-jhipster/pull/29092))
[MOCK] * Many internal and clean code improvements

[MOCK] ## How to install
[MOCK] 
[MOCK] To install JHipster v8.10.0:
[MOCK] 
[MOCK] ```
[MOCK] npm install -g generator-jhipster@8.10.0
[MOCK] ```
[MOCK] 
[MOCK] It is also available using the JHipster Docker image, as it is automatically built from our source code.
[MOCK] 
[MOCK] - [JHipster Online](https://start.jhipster.tech)
[MOCK] - [JHipster Devbox](https://github.com/jhipster/jhipster-devbox)

[MOCK] ## How to upgrade
[MOCK] 
[MOCK] **Automatic upgrade**
[MOCK] 
[MOCK] For an automatic upgrade, use the [JHipster upgrade sub-generator](/upgrading-an-application/) on an existing application:
[MOCK] 
[MOCK] Upgrade your version of JHipster:
[MOCK] 
[MOCK] ```
[MOCK] npm update -g generator-jhipster
[MOCK] ```
[MOCK] 
[MOCK] And then run the upgrade sub-generator:
[MOCK] 
[MOCK] ```
[MOCK] jhipster upgrade
[MOCK] ```
[MOCK] 
[MOCK] You can also use the [migrate blueprint](https://github.com/jhipster/generator-jhipster-migrate) for more advanced upgrade features.
[MOCK] 
[MOCK] ```
[MOCK] npm i -g generator-jhipster-migrate
[MOCK] jhipster-migrate
[MOCK] ```
[MOCK] 
[MOCK] **Manual upgrades**
[MOCK] 
[MOCK] For a manual upgrade, first upgrade your version of JHipster with:
[MOCK] 
[MOCK] ```
[MOCK] npm update -g generator-jhipster
[MOCK] ```
[MOCK] 
[MOCK] If you have an existing project, it will still use the JHipster version with which it was generated.
[MOCK] To upgrade your project, you must first delete its `node_modules` folder and then run:
[MOCK] 
[MOCK] ```
[MOCK] jhipster
[MOCK] ```
[MOCK] 
[MOCK] Since JHipster 8.0, this command will update your project and all its entities.
[MOCK] 
[MOCK] You can also update your entities one-by-one by running again the entity sub-generator, for example if your entity is named _Foo_, use:
[MOCK] 
[MOCK] ```
[MOCK] jhipster entity Foo --single-entity
[MOCK] ```
