# JHipster v9.1.0 リリース

これはJHipster v9のマイナーリリースです。

本リリースには、[9.0.0リリース](/2026/03/10/jhipster-release-9.0.0.html)以降の[878件のクローズされたイシューとプルリクエスト](https://github.com/jhipster/generator-jhipster/issues?q=is:closed+milestone:9.1.0)が含まれています。

## 新機能

* Typescriptのサポートを改善しました。各ジェネレーターが独自の型をエクスポートします。新しいブループリントはTypescriptで生成されます。
* Spring Boot [4.0.6](https://github.com/jhipster/generator-jhipster/pull/33553)にアップグレードしました。
* [セキュリティのための設定サニタイズ](https://github.com/jhipster/generator-jhipster/pull/32708)により、生成されたアプリケーションを強化しました。
* [すべてのコンポーネントでのOnPush変更検知](https://github.com/jhipster/generator-jhipster/pull/33218)と[書き直されたサービスワーカープロバイダー](https://github.com/jhipster/generator-jhipster/pull/33329)により、生成されたAngularアプリを改善しました。
* [JestからVitestへの移行](https://github.com/jhipster/generator-jhipster/pull/33200)と[react-redux-loading-barをreact-top-loading-barに置き換える](https://github.com/jhipster/generator-jhipster/pull/33039)ことにより、生成されたReactアプリを改善しました。
* [@module-federation/vite](https://github.com/jhipster/generator-jhipster/pull/33283)、[デフォルトでのrsbuildマイクロフロントエンド](https://github.com/jhipster/generator-jhipster/pull/33455)、そして[モジュールフェデレーションによるゲートウェイリソースのロード](https://github.com/jhipster/generator-jhipster/pull/33485)により、Vueマイクロフロントエンドのモダナイゼーションを継続しました。
* ビルドツールを[Node 24.16.0](https://github.com/jhipster/generator-jhipster/pull/33505)、[Gradle 9.5.1](https://github.com/jhipster/generator-jhipster/pull/33382)、そして[Maven 3.9.16](https://github.com/jhipster/generator-jhipster/pull/33439)にアップグレードしました。

## インストール方法

NPMを使用してJHipster v9.1.0をインストールするには：

```
npm install -g generator-jhipster@9.1.0
```

JHipster Dockerイメージを使用しても利用可能です。これはソースコードから自動的にビルドされるためです。

- [Docker Hub](https://hub.docker.com/r/jhipster/jhipster)
- [JHipster Online](https://start.jhipster.tech)

## アップグレード方法

**自動アップグレード**

自動アップグレードの場合、既存のアプリケーションで[JHipsterアップグレードサブジェネレーター](/upgrading-an-application/)を使用してください：

JHipsterのバージョンをアップグレードします：

```
npm update -g generator-jhipster
```

そして、アップグレードサブジェネレーターを実行します：

```
jhipster upgrade
```

より高度なアップグレード機能には、[migrateブループリント](https://github.com/jhipster/generator-jhipster-migrate)も使用できます。

```
npm i -g generator-jhipster-migrate
jhipster-migrate
```

**手動アップグレード**

手動アップグレードの場合、まずJHipsterのバージョンを以下でアップグレードしてください：

```
npm update -g generator-jhipster
```

既存のプロジェクトがある場合、それは生成されたJHipsterのバージョンを使い続けます。
プロジェクトをアップグレードするには、まず`node_modules`フォルダーを削除し、その後以下を実行する必要があります：

```
jhipster
```

プロジェクトとそのすべてのエンティティを更新するには、以下を実行することもできます：

```
jhipster --with-entities
```

エンティティサブジェネレーターを再度実行することで、エンティティを一つずつ更新することもできます。例えば、エンティティ名が_Foo_の場合：

```
jhipster entity Foo --single-entity
```
